# مستندات پیاده‌سازی

## قرارداد پروژه

این پروژه بر اساس `AI-BUILD-SPEC.md` توسعه داده می‌شود. کدها انگلیسی هستند و تمام متن‌های رابط در فایل‌های ترجمهٔ فارسی نگهداری خواهند شد. منطقهٔ زمانی برنامه `Asia/Tehran` و رابط کاربری RTL است.

## پشتهٔ فنی

- Laravel 13 و PHP 8.3+
- Livewire 4 و Alpine.js برای رابط‌های تعاملی
- Tailwind CSS 4 با پیکربندی CSS-first
- MySQL 8، Redis و Horizon
- Pest 3، Laravel Pint و Larastan سطح 6

## وضعیت فازها

| فاز | موضوع | وضعیت |
| --- | --- | --- |
| ۰ | اسکلت، ابزارهای کیفیت و تنظیمات محلی | انجام شد |
| ۱ | مدل دامنه، مهاجرت‌ها و دادهٔ آزمایشی | در انتظار تأیید |
| ۲ تا ۹ | ثبت‌نام، بلیط، پنل و استقرار | در انتظار فازهای بعد |

## راه‌اندازی

1. `.env.example` را به `.env` کپی کنید و اتصال MySQL و Redis را وارد کنید.
2. کلید برنامه را بسازید: `php artisan key:generate`.
3. مهاجرت‌ها را اجرا کنید: `php artisan migrate`.
4. وابستگی‌های فرانت‌اند و فایل‌های تولیدی را بسازید: `npm install && npm run build`.

## کنترل کیفیت

تست‌ها، قالب‌بندی و تحلیل ایستا به‌ترتیب با `./vendor/bin/pest`، `./vendor/bin/pint --test` و `./vendor/bin/phpstan analyse` اجرا می‌شوند.

## سازگاری نسخه‌ها

Laravel 13 با PHPUnit 12 نصب می‌شود، اما قرارداد پروژه Pest 3 را الزام کرده است. Pest 3 به PHPUnit 11 نیاز دارد؛ به همین دلیل PHPUnit روی 11 قفل شده است. افزونهٔ `pest-plugin-laravel` نسخهٔ 3 از Laravel 13 پشتیبانی نمی‌کند، پس عمداً نصب نشده است. تست‌های Feature با کلاس پایهٔ خود Laravel در `tests/Pest.php` پیکربندی شده‌اند.
